# Screen Recording Checklist - Maximum 10 Minutes

Do not explain the source code. Demonstrate only the application execution.

## Suggested Recording Flow

1. Open the project folder.
2. Run the application:

```bash
streamlit run app.py
```

3. Open the Add User tab and add a valid user.
4. Try adding a user with an empty field and show the error message.
5. Try adding a user with an incorrect birth date format and show the error message.
6. Try adding a user with an existing phone number and show the uniqueness error.
7. Open the Display Users tab and show all users in the table.
8. Open the Search User tab and search by first name, last name, birth date, birth place, and phone number.
9. Open the Update User tab, select a user, and update one or more fields.
10. Open the Delete User tab, select a user, confirm deletion, and delete the user.
11. End by showing that the database changes are reflected in the GUI.

## Commentary Example

"This is my Advanced User Management System. I will demonstrate add, display, search, update, and delete operations using a Streamlit GUI connected to MongoDB."
